# TWINROOZI 유튜브 채널

상위 문서: `트윈루지컴퍼니.md`

## 채널 한 줄 소개
쌍둥이 **루루**와 **지지**가 언니 **조안나**와 함께 일상과 맛있는 음식을 나누는 채널.

## 핵심 메시지 (확정)
> **한국 자매들과 같이 노는 것 같은, 친구 같은 채널**

제목, 썸네일, 대사, 분위기를 정할 때 이 문장을 기준으로 삼는다.
- 시청자를 구경꾼이 아니라 같이 노는 친구로 대한다. 말을 걸고, 같이 고르고, 같이 맛본다.
- 가르치거나 과시하는 말투보다 친구끼리 수다 떠는 말투를 쓴다.

## 시그니처 인사
- 대표 구호: **"쌍둥이 루!지!"** (원문 표기 그대로 쓴다. 느낌표 위치 포함)
- 끝 인사: **"그럼 또 만나자! 안녕~"** (원문 그대로 쓴다)
- 구독자 애칭: **칭구** ("친구"를 귀엽게 말한 한국어). 예: "칭구들 안녕!"

## 등장인물
| 이름 | 관계 | 역할 | 성격·특징 |
|---|---|---|---|
| 루루 | 쌍둥이 | 출연 | 맛있게 먹는다. 의리가 좋다. 운동을 좋아하고 잘한다. |
| 지지 | 쌍둥이 | 출연 | 운동과 공부를 잘하지만 루루에게 열등감을 느낀다. 엉뚱한 매력이 있고 아이디어가 좋다. |
| 조안나 | 루루·지지의 언니 (10살 위) | 출연, 외부 촬영 담당 | 착하고 명랑하며 사람을 좋아한다. 한국말을 잘한다. 요리를 정말 잘한다 (대학 조리학과 졸업). |

### 조안나의 요리
- 엄마와 쌍둥이가 케이크나 인도 음식을 자주 부탁한다.
- 채널에서 "요리하는 언니" 역할로 활용할 수 있다.

### 세 사람의 기본 역할 (확정)
- **조안나:** 만든다 (요리하는 언니)
- **루루:** 맛있게 먹는다 (의리 있는 먹보)
- **지지:** 엉뚱한 아이디어를 낸다 (모험의 시작)

### 쌍둥이 공통
- 한국 음식을 좋아한다.
- 잡식성이라 뭐든 잘 먹는다. 단, **파, 마늘, 양파는 싫어한다.**

### 조안나와 쌍둥이의 관계
- 쌍둥이가 태어날 때 곁에서 지켜봤고, 엄마와 함께 아이들을 돌봤다.
- 조안나는 쌍둥이를 자식처럼 느끼고, 쌍둥이는 조안나를 엄마처럼 따른다.

### 조안나 배경
- 공개 범위: "방글라데시에서 온 언니"까지만 쓴다. 그 밖의 개인사는 콘텐츠에 쓰지 않는다.

### 생김새
| | 실제 | 캐릭터 |
|---|---|---|
| 루루 | 단발, 앞머리 없음 | 양쪽으로 땋은 머리, 앞머리 없음 |
| 지지 | 단발, 앞머리 있음 | 양쪽으로 땋은 머리, 앞머리 있음 |

캐릭터에서 둘을 구분하는 가장 중요한 표시는 **앞머리 유무**다.

### 캐릭터 디자인 (ChatGPT 시안 기준, `animation/characters/` 참고)
- 그림체: 3D 애니메이션 스타일. 큰 눈, 둥근 얼굴, 밝게 웃는 표정
- 둘 다 양쪽으로 땋은 머리에 **동그란 안경**을 쓴다.
- 기본 의상은 반팔 티셔츠 + 멜빵바지(밑단을 접어 올림) + 운동화다. 직업이나 운동 테마에 따라 위에 의상과 소품을 더한다.

| | 루루 (왼쪽) | 지지 (오른쪽) |
|---|---|---|
| 앞머리 | 없음 (가운데 가르마) | 있음 |
| 머리색 | 검은색에 가까운 진갈색 | 밝은 갈색 |
| 안경 | **노란색** 동그란 테 | **핫핑크** 동그란 테 |
| 머리끈 | 주황색 | 연두색 |
| 티셔츠 | 노란색 | 핑크색 |
| 멜빵바지 | 청색 데님 | 핑크 데님 |
| 운동화 | 민트색 | 주황색 |
| 대표 색 | **노랑** | **핑크** |

- 두 사람을 나란히 세울 때는 루루를 왼쪽, 지지를 오른쪽에 둔다.

### 캐릭터 나이 (확정)
- **메인 캐릭터는 지금 시안 그대로** 귀여운 어린아이 비율을 유지한다.
- 이건 그림체일 뿐이고, 실제 루루와 지지는 18살이다. 대사나 설명에서 아이로 말하지 않는다.
- **성인 루지**(18살 모습)는 가끔 **카메오**로만 등장한다.

### 이미지 만들 때 주의
- 실제 구단, 브랜드의 이름과 로고(예: LG트윈스, 나이키)는 넣지 않는다. 상표 문제가 생길 수 있다. 팀 유니폼에는 자체 이름(예: TWINROOZI)을 쓴다.
- AI가 만든 글자는 자주 틀리므로(예: "LG퇴원스") 이미지 속 글자는 꼭 확인한다.

## 채널 역사
- 쌍둥이가 초등학교 3학년 때 시작했다.
- 기존 대표 콘텐츠는 먹방이다.
- 중학교 3학년 8월부터 공부에 전념하면서 업로드를 멈췄다. 지금은 고등학교 2학년이고, 약 2년 동안 새 영상이 없다.
- 쌍둥이는 현재 **18살 성인**이다. 아이로 묘사하지 않는다.

## 구독자
- 약 60%가 인도네시아, 베트남 등 인구가 많은 동남아 국가에 있다.
- 새 타깃: 쌍둥이와 공감대를 나눌 수 있는 **동남아시아의 젊은 성인 여성**

## 재개 방향 (초안)
1. **다시 인사:** 기존 먹방 영상을 그대로 보여준다.
2. **변신:** 실제 모습이 자연스럽게 캐릭터 이미지로 바뀐다. "어? 우리 모습이 변했어!"
3. **모험·체험:** 캐릭터가 된 세 사람이 여러 모험과 체험을 한다.
   - 실제 외부 촬영 영상에 AI 합성
   - 맛집 소개
   - 유명 가수·드라마 소개 (조안나가 실제로 외부 촬영)
4. **확장:** 교육 등 여러 분야로 넓힌다.

영상 제작에는 AI를 활용한다.
**당분간은 실제 모습 대신 캐릭터로 출연한다.**

## 영상 형식
- **긴 영상 위주**, 한 편에 약 **5분**
- 긴 영상 한 편에서 **쇼츠를 나올 수 있는 만큼** 잘라서 만든다.
- 업로드: 당분간 **주 1편 이상** (긴 영상 기준. 바뀔 수 있음)

## 언어
- 영상 속 말: **한국어 그대로**
- 자막: 유튜브 자동 자막과 자동 번역에 맡긴다 (외국어 자막을 따로 만들지 않음).

## 미정 (브레인스토밍으로 채울 것)
- 조안나 본인의 공개 범위 동의 확인
- 조안나 캐릭터 생김새
- 성인 루지 카메오의 디자인
- 조안나 캐릭터 디자인
- 채널 톤과 금지 사항
