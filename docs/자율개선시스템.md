# 성과가 향상되는 자율 개선형 시스템 (Supabase `growth` 스키마)

작업 결과와 피드백을 학습 자산으로 쌓고, 다음 작업에 자동으로 반영해 성과를 올리는 구조.
- 위치: Supabase 프로젝트 **STORE-studio** (`odlenhvdonociempcenv`), 스키마 **`growth`**
- 쇼핑몰 테이블(`public`)과 분리. API에 노출되지 않음(서버·MCP에서만 접근). RLS 켜짐.
- 마이그레이션: `growth_self_improving_system`, `growth_start_run_ab_test`

## 순환 구조
```
목표(변수) ─▶ start_run ─▶ 작업(플레이북 + 학습 자산 + 최고 사례 적용) ─▶ record_result(점수·지표)
     ▲                                                                       │
     │                       add_feedback / add_learning ◀───────────────────┘
     └──── promote_champion (A/B 결과로 기본 방식 교체) · retire_weak_learnings (안 통하는 방법 은퇴)
```

## 테이블
| 테이블 | 내용 |
|---|---|
| `goals` | 목표: 제목, 작업 유형, 변수(jsonb), 측정 지표(`metric`), 목표값(`target`) |
| `playbooks` | 작업 유형별 작업 방식. 버전 관리, 성과 1위가 `is_champion` |
| `learnings` | 학습 자산(인사이트). 적용 횟수·성공 횟수 → 신뢰도 `(성공+1)/(적용+2)` |
| `runs` | 작업 1회: 입력, 결과물, 지표(jsonb), 점수(0~100) |
| `run_learnings` | 그 작업에 적용한 학습 (성과를 학습에 귀속) |
| `feedback` | 사용자·시청자·플랫폼 피드백 |
| 뷰 | `v_learning_rank`, `v_playbook_perf`, `v_goal_progress` |

작업 유형(`task_type`): `shorts_script`(쇼츠·릴스 대본), `ad_plan`(제품 광고 기획), `image_prompt`(이미지 생성), `lecture`(강의 콘텐츠), `all`(공통 학습).

## 함수
```sql
-- 1) 목표 등록 (변수로 전달)
insert into growth.goals (title, task_type, metric, target, variables)
values ('녹차김 릴스 3초 유지율 60%', 'shorts_script', 'retention_3s', 60, '{"product":"녹차김","platform":"reels"}')
returning id;

-- 2) 작업 시작: 챔피언 플레이북(신규 버전은 50% 확률로 A/B 시험) + 신뢰도 상위 학습 + 탐색용 새 학습 1개 + 최고 사례 3개
select growth.start_run('shorts_script', <goal_id>, '{"product":"녹차김"}', '요청 내용');

-- 3) 결과 기록: 점수 70 이상이면 적용된 학습의 성공 횟수 +1, 목표 지표가 target 이상이면 목표 achieved
select growth.record_result(<run_id>, '결과물', 82, '{"retention_3s":64,"views":1200,"ctr":3.1}');

-- 4) 피드백 / 새 학습 / 개선된 플레이북
select growth.add_feedback(<run_id>, 5::smallint, '훅이 강했음', '{훅}', 'user');
select growth.add_learning('shorts_script', '첫 1초에 완성된 결과물을 먼저 보여주면 3초 유지율이 올랐다', '{훅}', 'metric', '[{"run_id":12}]');
select growth.add_playbook('shorts_script', '쇼츠 v2: 결과 선공개 훅', '…새 지침…', <parent_id>);

-- 5) 정기 정리
select growth.promote_champion('shorts_script', 3);   -- 3회 이상 시험된 버전 중 평균 점수 1위를 기본으로
select growth.retire_weak_learnings(5, 0.3);         -- 5회 이상 적용했는데 신뢰도 0.3 미만이면 은퇴
select * from growth.v_goal_progress;
```

## 점수 기준 (0~100)
실제 지표가 있으면 지표 우선, 없으면 사용자 평가로 환산한다.
- 사용자 평가: ★5 = 95, ★4 = 80, ★3 = 60, ★2 = 40, ★1 = 20
- 지표 예: 3초 유지율, 평균 시청 지속률, CTR, 저장·공유 수, 전환율, 광고 ROAS
- 성공 기준: 70점 이상 (`record_result`의 `p_success_threshold`로 조정)

## 한계 (사실대로)
- DB는 기록·순위·선택을 자동으로 하지만, **인사이트를 글로 뽑는 일**(`add_learning`)과 **새 플레이북 작성**은 Claude가 작업 세션에서 한다.
- 실제 조회수·유지율은 지금은 사람이 입력한다. 다음 단계: Meta 광고·YouTube Analytics 지표를 자동으로 `runs.metrics`에 넣기.
- 표본이 적을 때(실행 3회 미만) 순위는 참고용이다.
