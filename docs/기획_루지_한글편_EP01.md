# 쌍둥이루지 TWINROOZI — 간판 캐릭터 & 한글편 EP01 기획

## 1. 캐릭터 설정

| | **루 (ROO)** | **지 (ZI)** |
|---|---|---|
| 외모 | 검은 생머리 양갈래 땋은 머리, 주황 머리끈 | 앞머리 있는 갈색 머리 양갈래, 연두 머리끈 |
| 안경 | 노란 동그란 안경 | 핑크 동그란 안경 |
| 의상 | 주황 티셔츠 + 청 멜빵바지, 민트 운동화 | 핑크 티셔츠 + 핑크 멜빵바지, 주황 운동화 |
| 대표 색 | 노랑/주황 | 핑크 |
| 성격 | 먼저 뛰어드는 행동파, 호기심 폭발, 살짝 덜렁 | 메모하는 꼼꼼파, 설명 담당, 은근 웃긴 한마디 |
| 입버릇 | "가 보자고!" | "잠깐, 이거 알아?" |
| 역할 | 한국을 처음 겪는 시청자 시점 | 한글 선생님 시점 |

**케미 공식**: 루가 먼저 저지른다 → 지가 설명한다 → 둘이 같이 단어를 외친다 → 하이파이브.
매 에피소드 끝에 둘만의 인사 동작(손바닥 마주치고 안경 올리기)으로 마무리.

**제작 팁**
- 지금 이미지 3장이 좋은 기준입니다. 이걸로 **정면/측면/뒷모습 턴어라운드 + 표정 8종(기쁨, 놀람, 궁금, 뿌듯, 당황, 감동, 졸림, 응원)** 시트를 먼저 만들어 두면 매 컷 얼굴이 흔들리지 않습니다.
- 둘을 한눈에 구분하는 건 **안경 색(노랑 vs 핑크)** 이 가장 강력합니다. 모든 소품·자막 색도 이 두 색에 맞추세요.

## 2. 시리즈 콘셉트

**「루지의 한글 산책」** — 매 편 하나의 한국 장소에서 단어 6~8개를 줍는다.
- 시청자: 10대 소녀, 해외 팬 포함 → 화면에 **한글 + 로마자 + 영어** 3줄 표기.
- 단어 하나는 3번 반복: ① 화면에 크게 등장 ② 루지가 천천히 발음 ③ 장면 속에서 실제로 사용.
- **오늘의 자음** 코너: 단어의 첫 글자에서 자음 하나를 뽑아 모양을 그림으로 외우게 함
  (예: ㅎ = 모자 쓴 사람, ㅈ = 지하철 문이 열리는 모양).

## 3. EP01 「안녕, 서울!」 — 8분 구성안

| 시간 | 장면 | 단어 (한글 / 로마자 / 뜻) | 한국 문화 포인트 | 루지 케미 |
|---|---|---|---|---|
| 0:00–0:25 | 콜드 오픈: 색종이 속 둘이 손 흔들기 | **안녕하세요** / annyeonghaseyo / Hello | 고개 살짝 숙이는 인사 | 루는 손 흔들고, 지는 고개 숙여 인사 → 서로 따라 하다 꼬임 |
| 0:25–0:50 | 오프닝 + 미션 | — | "오늘 한글 스티커 8개 모으기!" | 스티커북을 지가 들고, 루가 뺏어 달림 |
| 0:50–1:50 | 지하철 | **지하철** / jihacheol / subway, **삑!** | 교통카드 태그, 깨끗한 역, 스크린도어, 임산부 배려석 | 루가 카드 대는 걸 까먹어 개찰구에서 멈춤 / 오늘의 자음 **ㅈ** |
| 1:50–2:50 | 횡단보도 | **횡단보도** / hoengdanbodo / crosswalk, **초록불** | 바닥 신호등(LED), 횡단보도 그늘막, 음성 안내 | 루가 폰 보며 걷다 바닥 불빛을 보고 멈춤 → "한국은 바닥도 신호등이야!" / 오늘의 자음 **ㅎ** |
| 2:50–4:00 | 편의점 | **편의점** / pyeonuijeom / convenience store, **라면** | 즉석 라면 기계, 삼각김밥 뜯는 법(1-2-3), 바나나우유 | 루가 삼각김밥을 잘못 뜯어 김이 찢어짐 → 지가 순서대로 시범 |
| 4:00–5:20 | K-팝 무대 / 연습실 | **노래** / norae / song, **춤** / chum / dance, **응원해요** | 응원봉, 떼창 문화, 댄스 챌린지 | 둘이 짧은 챌린지 안무 → 지는 완벽, 루는 반 박자 늦지만 더 신남 |
| 5:20–6:20 | 안전한 밤거리 | **밤** / bam / night, **안전** / anjeon / safe | 카페 테이블에 폰 두고 가도 그대로, 밤에도 밝은 거리, 24시간 가게 | 루가 폰을 두고 나왔다가 돌아왔는데 그대로 → 둘이 안도 |
| 6:20–7:20 | 복습 퀴즈 | 8개 단어 그림 맞히기 | — | 루 vs 지 대결, 시청자도 같이 맞히도록 3초 대기 |
| 7:20–8:00 | 엔딩 | **감사합니다**, **또 만나요** | — | 하이파이브 + 안경 올리기, 다음 편 예고(한강 / 떡볶이) |

### 대사 샘플 (지하철 장면)
> 루: 가 보자고! (개찰구에서 쾅 막힘) 어… 왜 안 열려?
> 지: 잠깐, 이거 알아? 카드를 여기 대야 해. **삑!**
> 루: 삑! 이게 한국어야?
> 지: 그건 소리고~ 이건 **지하철**. 지·하·철.
> 둘: **지하철!** (스티커 획득 효과음)

## 5. 꼭 확인할 것 — 실존 가수(BTS 등)

- 실제 아이돌의 **이름·얼굴·곡·안무·로고**를 애니메이션에 그대로 쓰면 초상권·저작권 문제가 생기고 채널 수익화가 막힐 수 있습니다.
- 대신 **K-팝 문화 자체**를 보여주세요: 응원봉, 떼창, 댄스 챌린지, 연습실, 음악 방송 무대 분위기.
  필요하면 루지 세계관 속 **가상 아이돌 그룹**을 만들고 노래도 직접 만든 곡을 쓰면 안전합니다.
- "BTS가 유명한 나라" 정도의 짧은 언급은 괜찮지만, 그들을 캐릭터로 그리거나 협업처럼 보이게 하진 마세요.

## 6. 우리 편집기로 할 수 있는 부분

이 저장소 편집기는 이미 **한글 글자를 AI 그림 안에 넣지 않고 우리가 직접 그립니다** (AI가 한글을 틀리기 때문).
한글 단어 카드(크림색 종이 + Gaegu 글씨)와 말풍선이 바로 이 시리즈의 "단어 스티커"와 같은 역할을 하므로,
애니메이션 본편을 만든 뒤 `plan.json`에 단어 카드 시간을 적어 `cli.py 영상.mp4 --plan plan.json`으로 입히면
카드 디자인을 매 편 똑같이 유지할 수 있습니다.
