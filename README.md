# 🎬 키즈 유튜브 AI 편집기

영상을 올리면 **AI 설명 그림**과 **쌍둥이 캐릭터**가 영상 위에 나와요.

- **설명 그림**: 아이들이 떠올리기 어려운 것(음식, 동물, 장소, 만드는 과정 등)이 나오는 순간을 Claude가 고릅니다. 그 장면을 ChatGPT가 플랫 벡터와 손그림 카툰 스타일로 그려서 종이 카드에 담아 '뿅' 하고 띄워요.
  - 그림 안에는 글자를 넣지 않아요. 이미지 AI는 한글을 자주 틀리기 때문이에요. 짧은 이름표가 필요하면 그림 아래에 손글씨 폰트로 따로 넣습니다.
- **쌍둥이 캐릭터**: 쌍둥이가 귀여운 캐릭터가 되어 화면 아래 구석에서 쏙 올라와 말풍선과 이모지로 반응해요. "우와! 면이 이렇게 길어?" → "너 또 배고프지? ㅋㅋ"처럼 둘이 주고받는 케미도 보여 줍니다.
  - A는 왼쪽, B는 오른쪽에 나오고 이름표가 붙어요.
  - 아이 사진을 올리면 그 아이를 닮은 캐릭터로 그려요. 사진이 없으면 적어 둔 생김새를 보고 새로 디자인합니다.
  - 기본 모습을 먼저 그린 다음 그 그림을 바탕으로 다른 포즈를 그려서, 영상 내내 같은 캐릭터로 보여요.
  - 포즈는 10가지입니다: 웃기, 손 흔들기, 가리키기, 생각하기, 놀라기, 깔깔 웃기, 먹기, 엄지척, 환호, 수줍음.
- **가로(16:9)·세로(9:16, 쇼츠) 영상**을 모두 지원해요. 세로 영상은 그림을 위쪽 가운데에 크게 띄웁니다.
- 원본 영상은 자르지 않아요(컷 편집 없음). 그림과 캐릭터만 얹습니다.

## 실행 방법

1. `.env.example`을 복사해 `.env`로 이름을 바꾸고 키를 넣습니다.
   - `ANTHROPIC_API_KEY`: 그림과 반응을 어디에 넣을지 계획합니다.
   - `OPENAI_API_KEY`: 그림과 캐릭터를 그립니다.
2. **`실행.bat` 더블클릭**: 처음에는 필요한 프로그램을 설치하고(10~20분), 브라우저에 편집 화면이 열립니다.
   - **코드가 바뀌면 자동 반영**: 켜 둔 채로 코드가 바뀌면 몇 초 안에 새 코드로 바뀝니다. 브라우저만 새로고침하세요. `실행.bat`을 다시 실행할 필요가 없어요.
   - **GitHub 자동 업데이트**: git 으로 받은 폴더라면 작은 "자동 업데이트" 창이 1분마다 GitHub의 새 코드를 받아옵니다. 분석이나 영상 만들기가 진행 중일 때는 끝날 때까지 기다렸다가 받아요.
   - `.env`의 키를 바꾸면 다음 분석부터 바로 적용됩니다.
3. 화면에서 순서대로 진행합니다.
   1. 영상을 올리고 쌍둥이 이름·생김새(선택: 사진)를 적습니다.
   2. **1. 분석하기**: 음성 인식 → Claude 계획 → 그림·캐릭터 동시 생성이 진행되고, 미리보기에 첫 장면이 나와요.
   3. 미리보기 시간 슬라이더로 원하는 장면을 확인합니다. 미리보기는 최종 영상과 똑같이 그려져요.
   4. (선택) **계획 직접 고치기**: 시간, 대사, 포즈, 이모지를 고친 뒤 **고친 계획 적용**을 누르면 AI를 다시 부르지 않고 바로 반영돼요. 이미 그린 그림은 저장돼 있어서 비용이 들지 않습니다.
   5. **2. 영상 만들기**를 누릅니다.

명령줄로도 실행할 수 있어요.

```bash
.venv\Scripts\python cli.py 영상.mp4 --twin-a 하윤 --twin-b 하린 --desc-a "양갈래 머리, 노란 티셔츠" --photo-a 하윤.jpg --topic "마라탕 먹방"
.venv\Scripts\python cli.py 영상.mp4 --plan jobs\20261107_120000\plan.json
```

## 결과물 (`jobs/날짜_시간/`)

- `결과영상.mp4`
- `편집리포트.html`: 그림과 반응이 언제 나오는지 정리한 표
- `plan.json`: 계획. 고쳐서 다시 렌더할 수 있어요.
- `transcript.json`: 음성 인식 결과
- `card_XX.png`, `characters/`: 그림 카드와 캐릭터
- `log.txt`

## 키가 없을 때

- Claude 키가 없으면 그림과 캐릭터를 어디에 넣을지 정할 수 없어요. 대신 `plan.json`을 직접 써서 넣을 수는 있습니다.
- OpenAI 키가 없으면 설명 그림은 빠지고, 쌍둥이는 기본 캐릭터 그림으로 나와요.
