# 🎬 자동 영상 편집기 (설교 영상)

영상을 올리면 아래 순서로 자동 편집합니다.

1. **트림**: 시작점/종료점을 정하면 앞의 인트로와 뒤의 엔딩을 잘라냅니다(`2:15`, `42:30`처럼 입력).
2. **1차 컷**
   - 무음 구간 단축: 1초 이상 조용한 곳을 앞뒤 0.25초만 남기고 줄입니다. 설교의 의도적인 짧은 쉼은 남겨요.
   - 필러워드 제거: "어", "음"은 항상 자릅니다. "그", "뭐", "이제"처럼 진짜 말일 수도 있는 단어는 Claude가 문맥을 보고 판단해 자르고, 성경 낭독과 기도 부분은 건드리지 않아요.
3. **설교자 가운데 맞춤**: 얼굴을 찾아 설교자를 화면 가운데로 자동 정렬합니다. 필요한 만큼만 살짝 확대해서 검은 여백이 생기지 않아요.
   - 좌/우, 상/하 슬라이더로 미세 조절할 수 있어요.
   - 확대 슬라이더로 더 크게 잡을 수 있어요.
   - "따라가기"를 켜면 설교자가 강단을 오갈 때 카메라가 천천히 따라갑니다.
4. **제목·이름**
   - 설교 제목: 켜기/끄기, 좌측·중앙·우측 정렬, X/Y 미세 조절, 표시 시간(0이면 계속)을 정할 수 있어요.
   - 설교자 이름: 항상 설교자 아래쪽, 인물 가운데에 자동으로 붙어 다닙니다.
5. **설명 그림**: Claude가 그림이 이해를 도울 순간(성경 지명, 풍습, 비유 등)을 고르면, ChatGPT 이미지 모델이 플랫 벡터 + 손그림 카툰 스타일로 그립니다. 기존 종이 카드 틀에 넣어 화면 오른쪽이나 전체 화면에 보여 줘요.
   - 그림은 **모두 동시에(병렬로)** 그리고, 그동안 다른 작업을 계속 진행합니다. 기본은 동시 6개이고, `.env`의 `OPENAI_IMAGE_CONCURRENCY`로 바꿀 수 있어요.
   - 90초 넘게 걸리는 그림은 빠른 설정(저화질)으로 다시 그립니다.
   - 한 번 그린 그림은 저장해 두어서, 같은 설교를 다시 렌더링할 때는 새로 그리지 않아요(비용 0원).
6. **결과물**(`jobs/날짜_시간/` 폴더)
   - `결과영상.mp4`
   - `편집리포트.html`
   - `자막.srt`
   - 작업 기록: `transcript.json`, `analysis.json`, `cards/`, `log.txt`

## 실행 방법

1. **`실행.bat` 더블클릭**: 브라우저에 편집 화면이 열립니다.
   - **자동 반영**: 켜 둔 채로 프로그램이 업데이트되면(코드 수정, `git pull`) 몇 초 안에 새 버전이 적용돼요. 브라우저만 새로고침하면 됩니다.
   - `.env`에 API 키를 넣거나 바꾸면 다음 미리보기나 편집부터 바로 적용돼요.
   - 단, 긴 설교를 **편집하는 도중**에 코드가 바뀌면 그 작업이 끊길 수 있으니 업데이트는 편집이 끝난 뒤에 하세요.
2. 영상을 올리면 **미리보기**가 자동으로 나옵니다. 위치·제목·이름 슬라이더를 움직이면 미리보기가 바로 바뀌어요.
3. 마음에 들면 **편집 시작**을 누르세요.

명령줄에서 실행할 수도 있습니다.

```bash
.venv\Scripts\python cli.py 설교.mp4 --start 2:10 --end 41:30 --title "두려워하지 말라" --name "홍길동 담임목사"
```

## API 키 (`.env` 파일)

| 키 | 용도 | 없으면 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 대본 분석(필러 판단, 그림 넣을 위치) | "어/음"만 자르고 그림 없음 |
| `OPENAI_API_KEY` | 설명 그림 생성(ChatGPT 이미지) | 그림 없음 |

`.env.example`을 복사해 `.env`로 이름을 바꾸고 키를 넣으세요. 키는 `.env.example`이 아니라 `.env`에만 넣어 주세요.

## 참고

- 40분 설교 기준 처리 시간은 대략 20~40분입니다.
- 얼굴을 못 찾으면(뒷모습, 아주 먼 화면 등) 자동 맞춤 없이 슬라이더로 정한 위치만 적용됩니다.
- 설교자 외에 화면에 더 크게 잡히는 얼굴이 있으면 그 사람을 기준으로 맞출 수 있으니 미리보기로 확인하세요.
